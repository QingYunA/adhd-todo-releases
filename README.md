# ADHD Todo releases

Installers and update files for [ADHD Todo](https://adhd-todo.sri-ai.xyz/): a to-do app built around one input box, with a board that shows what your coding agents are doing.

Download the latest version from [Releases](https://github.com/QingYunA/adhd-todo-releases/releases/latest):

- **macOS** (Apple silicon and Intel): `ADHD-Todo-<version>-macos-universal.dmg`. The first time, right-click the app and choose Open.
- **Windows** (x64): `ADHD-Todo-Setup-<version>-windows-x64.exe`.
- **Android**: `adhd-todo-<version>.apk`.

Installed apps update themselves from here. `SHA256SUMS.txt` lists the checksum of every file.

This repository holds releases only; the source is not here.
